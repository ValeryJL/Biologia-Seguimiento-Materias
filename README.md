# Seguimiento de Materias · Profesorado de Ciencias Biológicas (UNLP)

Mapa interactivo de seguimiento de materias, notas y correlatividades para el **Profesorado de Ciencias Biológicas** (FaHCE · UNLP · Plan 2003, Cód. 012).

🌐 **Sitio publicado:** https://bio.valeryjl.com.ar

## Funciones principales
- Mapa interactivo por año (materias anuales arriba y cuatrimestrales divididas en 1º y 2º cuatrimestre, arrastrables entre cuatrimestres) + capacitaciones de Idiomas.
- Seguimiento de estado académico (`Aprobada`, `Cursada`, `En curso`, `Pendiente`, `Recursa`), notas, fechas y observaciones personales guardadas localmente en el navegador.
- Trazado interactivo de correlatividades para cursar (`C`/`F`) y rendir final, con verificación automática de materias habilitadas.
- Importación directa de **Historia Académica** y **Plan de Estudios** de SIU Guaraní (PDF/XLS/CSV) y respaldo en JSON.
